With File Revision History, you can view the modification records of files and restore files to any version anytime, anywhere.

> [!note] Currently only supported for cloud disk synchronization.

Right-click (long-press on mobile devices) the open file tab to bring up the right-click menu, then select `Revision History` to view the file's modification records.

<img src="/img/revision-history-view.png" alt="File Revision History" width="75%">

- Click the `View` button to check the modification records of the file.
- Click the `Restore` button to revert the file to any version.
- Click the `Delete` button to remove any version of the file.
