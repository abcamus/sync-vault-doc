**白板（Canvas）** 插件聚焦于 “可视化知识连接”，**日记（Daily Notes）** 插件则专注于 “结构化时间记录”，二者分别从 “空间维度” 和 “时间维度” 为用户构建了高效的信息管理方式。以下将从插件功能、使用场景、操作技巧及联动玩法四方面，对两款核心插件进行全面解析。

## 一、核心插件：白板（Canvas）—— 无限画布，可视化知识网络

Obsidian 白板插件的核心定位是 “打破线性笔记的局限”，通过无限延伸的画布，将零散的笔记、图片、链接等元素以 “块” 的形式自由组合，直观呈现信息间的逻辑关系，尤其适合**头脑风暴**、**项目规划**与**知识体系梳理**。

### 1. 核心功能与元素

白板的操作围绕 “**元素添加**” 和 “**关系连接**” 展开，支持多种元素类型，满足不同场景需求：

| 元素类型             | 功能说明                                                        | 操作方式                          |
| ---------------- | ----------------------------------------------------------- | ----------------------------- |
| 笔记块（Note Card）   | 嵌入 Obsidian 库内已有的笔记，或在画布中直接新建笔记（新建笔记会自动存入库中）                | 点击左侧工具栏「笔记」图标，或拖拽库内笔记至画布      |
| 文本块（Text）        | 快速添加临时文本（如关键词、待办项、备注），无需创建独立笔记                              | 点击左侧工具栏「文本」图标，在画布空白处点击输入      |
| 媒体块（Image/File）  | 插入本地图片（支持 PNG/JPG/GIF）、PDF 等文件，直接在画布预览                      | 拖拽本地文件至画布，或点击工具栏「图片」图标选择文件    |
| 链接块（Link）        | 添加外部网页链接，点击可直接跳转至对应页面                                       | 点击工具栏「链接」图标，输入 URL 与显示名称      |
| 形状块（Shapes）      | 插入矩形、圆形、箭头等基础形状，用于划分区域、突出重点或引导逻辑流                           | 点击工具栏「形状」图标，选择形状后在画布拖拽绘制      |
| 连接线（Connections） | 连接任意两个元素，支持调整线条样式（实线 / 虚线）、颜色与箭头方向，直观展示逻辑关系（如 “包含”“因果”“递进”） | 鼠标 hover 元素边缘，出现「连接点」后拖拽至目标元素 |

### 2. 核心特性：无限画布与灵活编辑

- **无限延伸的画布**：画布无固定边界，可通过鼠标滚轮缩放（缩放范围 10%-1000%）、拖拽画布空白处移动，支持处理大规模信息（如完整项目流程、学科知识框架）。
- **元素自由编辑**：
    - 选中元素后，可拖拽调整位置、拉伸修改大小；
    - 右键元素可修改颜色（区分不同类别信息）、锁定位置（防止误操作）、复制 / 删除；
    - 文本块支持 Markdown 语法（如加粗、列表、链接），笔记块同步库内笔记修改（双向联动）。
- **导出与分享**：支持将白板导出为 PNG 图片（适合插入报告、分享给他人）或 Obsidian 专属的 `.canvas` 文件（保存在库内，可随时重新编辑）。

### 3. 典型使用场景

- **头脑风暴**：快速记录灵感（文本块），用连接线梳理灵感间的关联（如 “创意 A 衍生自创意 B”），后期将成熟灵感转化为独立笔记（笔记块）。
- **项目规划**：用笔记块记录项目任务（如 “需求调研”“原型设计”），用形状块划分任务阶段（如 “准备期”“执行期”），用箭头标注任务顺序，直观呈现项目流程。
- **知识梳理**：将某一主题的零散笔记（如 “心理学理论”“案例分析”）拖拽至画布，用连接线标注理论与案例的对应关系，构建可视化知识体系。

## 二、核心插件：日记（Daily Notes）—— 时间维度的结构化记录

Obsidian 日记插件的核心定位是 “以时间为轴，整合每日信息”，自动生成以 “日期” 命名的笔记（如 `2024-05-20.md`），帮助用户快速记录每日思考、待办、事件，同时通过双向链接关联其他笔记，形成 “时间 - 知识” 的联动网络。

### 1. 核心功能：自动化与结构化

- **自动生成日记笔记**：
    - 开启插件后，点击左侧工具栏「日历」图标，或使用快捷键（默认 `Ctrl+P` 搜索 “Daily Notes: Open today's note”），即可生成当日日记笔记，文件名默认遵循「YYYY-MM-DD」格式（可在设置中自定义，如「MM-DD-YYYY」）。
    - 支持 “回顾历史日记”：点击日历图标中的任意日期，可直接打开对应日期的日记；若该日期无日记，将自动创建空白笔记。
- **自定义日记模板（Template）**：
    - 插件支持设置 “日记模板”，新建日记时自动插入模板内容，避免重复排版。例如，可创建包含 “今日待办”“今日思考”“今日事件”“明日计划” 的模板，让每日记录更结构化。
    - 设置路径：「设置 → 核心插件 → Daily Notes → Template file location」，选择库内的模板笔记（如 `Templates/Daily Note Template.md`）即可。
- **时间戳与快捷插入**：
    - 支持插入当前时间戳（默认快捷键 `Ctrl+Shift+I`），格式为「HH:mm」（如「14:30」），适合记录具体时间点的事件（如 “14:30 完成会议纪要”）。
    - 部分第三方插件（如 Templater）可与日记插件联动，实现更灵活的时间插入（如 “本周总结”“本月计划” 自动关联当日日记）。

### 2. 核心特性：时间联动与信息整合

- **双向链接关联**：日记笔记可与库内其他笔记建立双向链接。例如，在 `2024-05-20.md` 中记录 “今日学习了 [[Obsidian 白板插件]]”，则在 “Obsidian 白板插件” 笔记的 “反向链接” 区域，会自动显示 `2024-05-20`，清晰追溯 “何时学习了该知识”。
- **标签与搜索整合**：可在日记中添加标签（如 `#工作` `#学习` `#生活`），后期通过 Obsidian 搜索功能（`Ctrl+F`）筛选特定标签的日记（如搜索 `#工作 2024-05`，快速定位 5 月的工作相关记录）。
- **跨设备同步**：日记笔记本质是 Markdown 文件，与其他 Obsidian 笔记一样支持通过 iCloud、OneDrive、Git 等工具跨设备同步，确保多端（电脑、手机、平板）的日记记录无缝衔接。

### 3. 典型使用场景

- **每日待办与复盘**：用模板中的 “今日待办” 记录任务，完成后标注「✅」，晚间在 “今日复盘” 中总结任务完成情况、遇到的问题及改进方向。
- **知识碎片记录**：每日阅读、学习时，将零散的知识点（如 “白板插件支持导出 PNG”）记录在当日日记中，后期通过双向链接关联至对应主题笔记（如 “Obsidian 白板插件”），避免知识遗漏。
- **生活事件记录**：记录每日重要事件（如 “今日与朋友聚餐”“今日完成健身”），搭配标签（`#生活 #健身`），长期积累后可通过搜索回顾生活轨迹，甚至生成年度总结。

## 三、白板与日记的联动玩法：时间 + 空间的双重信息管理

白板与日记插件并非独立存在，二者联动可实现 “时间维度的记录” 与 “空间维度的梳理” 结合，进一步提升信息管理效率：

  

1. **用白板梳理日记中的零散信息**：  
    每周 / 每月结束后，将该周期内日记中的关键信息（如 “完成的项目任务”“学到的知识点”“待解决的问题”）拖拽至白板（以笔记块形式），用连接线梳理信息间的关联（如 “任务 A 依赖知识点 B”），形成 “周期总结白板”，避免日记信息碎片化。
    
2. **在日记中嵌入白板链接，追踪项目进度**：  
    若用白板规划了某项目（如 “毕业论文写作”），可在每日日记中插入该白板的链接（`[[毕业论文写作.canvas]]`），记录当日在项目中的进展（如 “完成文献综述部分，更新白板中的「文献调研」任务状态”），实现 “每日记录” 与 “项目全局” 的联动。
    
3. **用白板制作 “日记时间线”**：  
    在白板中插入多个日记笔记块（按日期排序），用箭头标注每日事件的因果关系（如 “2024-05-18 确定论文题目 → 2024-05-20 完成文献调研”），直观呈现某一事件的发展脉络，适合复盘长期项目或重要事件。
    

## 四、基础设置与操作技巧

### 1. 插件开启与基础设置

- 开启插件：进入 Obsidian 「设置」→「核心插件」，找到「Canvas」（白板）和「Daily Notes」（日记），勾选 “启用” 即可。
- 日记插件关键设置：
    - 日期格式：自定义日记文件名（如「YYYY 年 MM 月 DD 日」）；
    - 模板设置：指定模板笔记，确保每日日记结构统一；
    - 快捷键：在「设置 → 快捷键」中搜索 “Daily Notes”，自定义 “打开今日日记”“打开昨日日记” 等操作的快捷键，提升操作效率。

### 2. 实用操作技巧

- 白板：按住 `Shift` 键可批量选中多个元素，统一移动或删除；选中连接线后，右键可修改线条颜色（如用红色标注 “待解决问题” 的关联）。
- 日记：在日记中使用「[[YYYY-MM-DD]]」格式链接其他日期的日记（如 `[[2024-05-19]]`），快速跳转至昨日 / 明日日记，方便追溯时间线；搭配「标签 + 搜索」（如搜索 `#待办 2024-05`），快速筛选未完成的任务。

  

通过白板与日记插件的配合，Obsidian 既满足了 “每日记录” 的结构化需求，又实现了 “知识梳理” 的可视化需求，无论是个人知识管理、项目规划还是生活记录，都能提供高效、灵活的解决方案。
